1. Pak zip-filen ud paa stationaeren.

2. Aabn PowerShell i mappen.

3. Installer dependencies:
   .\INSTALL_DDM.ps1

4. Start i toer-koersel:
   .\START_DDM.ps1

5. Aabn:
   http://127.0.0.1:5000

6. Login:
   jesaias / miebs112

LIVE-HANDEL MED COINBASE

1. Kopier DDM_ENV_TEMPLATE.ps1 til .env.local.ps1.

2. Udfyld Coinbase API key/secret.
   Brug kun view + trade.
   Brug aldrig withdraw/transfer.

3. Start appen:
   .\START_DDM.ps1

4. Log ind og koer "Preflight foer nattekoersel".

5. Foerst naar preflight er OK:
   - saet DDM_LIVE=1 i .env.local.ps1
   - saet DDM_LIVE_ARMED=JEG_FORSTAAR_RISIKOEN
   - genstart appen
   - koer preflight igen
   - start Autonom drift

AI-NOEGLER

Krypto-botten kraever ikke Gemini/OpenAI/Claude.
Du kan tilfoeje AI-noegler i fanen Settings.
AI-research er slaaet fra som standard for at spare tokens.

Bruges aktivt nu:
- Claude/ANTHROPIC_API_KEY: valgfri sports/AI-research.
- ODDS_API_KEY: valgfri live sports-odds.

Kan gemmes til senere, men bruges ikke af motoren endnu:
- OPENAI_API_KEY
- GEMINI_API_KEY

SPAR TOKENS

Krypto auto-trader bruger 0 AI-tokens.
Hvis du slaar AI-research til sport til, styrer Settings:
- max AI-kald pr. dag
- tokenbudget pr. dag
- web-soegning til/fra
- max output pr. kald

Lad AI-research vaere slaaet fra om natten, hvis du kun vil handle krypto.
